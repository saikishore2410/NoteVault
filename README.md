# 📝 NoteVault – Handwritten Notes Hub & AI Digitizer

NoteVault is a modern, responsive web application designed to help students, developers, and researchers digitize, search, and access handwritten notes across various academic and technical subjects.

Built with a clean front-end architecture and designed for integration with **Google AI Studio** and the **Gemini Vision API**, NoteVault enables quick navigation through digitized notebook pages, complete with interactive document viewing and automated text extraction (OCR).

---

## ✨ Features

- 🔍 **Instant Search & Filtering:** Quickly search notes by subject, topic tags, or keywords.
- 📖 **Interactive Note Viewer:** Built-in viewer with Zoom In/Out, page navigation, and multi-page thumbnail previews.
- 🤖 **AI Handwritten OCR:** Convert uploaded handwritten note images into searchable, editable text using Gemini Vision models.
- 🌓 **Dark / Light Mode:** Built-in theme toggle optimized for both daytime reading and late-night study sessions.
- 📱 **Responsive Design:** Fluid layout styled with Tailwind CSS, supporting mobile, tablet, and desktop screens.
- 📥 **Document Downloads:** Direct export links for full PDF/image sets.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern Vanilla JavaScript (ES6+)
- **Styling:** Tailwind CSS
- **Icons:** Lucide Icons / SVG Icons
- **AI Engine:** Google AI Studio / Gemini Vision API
